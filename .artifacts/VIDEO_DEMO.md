## Video Content

The video shows a complete walkthrough of the PatternDays web application:

### Scenes:

1. **Landing Page (2 sec)**
   - Marketing homepage with feature overview
   - Sign In and Sign Up buttons

2. **Sign Up Page (1.5 sec)**
   - Registration form with email and password fields
   - Form validation visible

3. **Back to Landing (1.5 sec)**
   - Clicking "Sign in" link
   - Navigation between pages

4. **Sign In Page (1.5 sec)**
   - Login form with email and password fields
   - "Sign in" button highlighted

5. **Dashboard (3 sec)**
   - Key metrics cards:
     - Active Habits: 2
     - Completion Rate: 71%
     - Best Streak: 5 days (Morning Exercise)
     - Entries: 7
   - Score Trends line chart
   - Habit Completion bar chart

6. **Dashboard Scroll Down (2 sec)**
   - Reveals Habit Impact analysis cards
   - Shows detailed comparisons for each habit
   - Displays insights and recent entries table

7. **Habits Page (2 sec)**
   - Shows 3 active habits
   - Add New Habit form
   - Archive buttons for each habit

8. **Entries Page (2.5 sec)**
   - Daily entries table with all data
   - Date, Mood, Energy, Focus, Notes columns
   - Scrolls to show more entries
